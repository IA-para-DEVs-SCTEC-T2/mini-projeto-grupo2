# Primeiro Commit

Este arquivo marca o início do projeto de análise de duplicatas em Java.

## O que foi feito

- `Duplicate.java` — implementação original com dois loops aninhados (O(n²))
- `DuplicateIA.java` — implementação otimizada com `HashSet` (O(n))
- `analise.md` — comparação entre as duas versões em legibilidade, eficiência e edge cases
- `historicoChat.md` — registro do histórico da conversa com o Kiro

## Conclusão inicial

A versão com `HashSet` é superior em tempo de execução e legibilidade, sendo a escolha recomendada para uso em produção.
